# 第一次使用：安装、定位设备、收发和测试

本页走 Python USB 路线：安装 → 权限与绑定 → 定位通道 → 收发 → 测试。直接使用 Linux SocketCAN 时，先看[驱动安装](08_Linux内核驱动安装.md)和[使用手册](09_SocketCAN使用手册.md)。Windows 命令以 `py` 开头，Linux/macOS 以 `python3` 开头，其余参数相同。Linux 日常使用 Python 不需要 sudo；首次设置 USB 权限、解绑内核接口需要管理员权限。

## 1. 准备设备和命令窗口

进入仓库的 `python-cli/` 目录，在 Windows 打开 PowerShell，在 Linux/macOS 打开终端。命令一次执行一行；不要复制终端提示符。

安装 Python 3.10 或更高版本。Windows 可从 [Python 官网](https://www.python.org/downloads/windows/)安装，并确认 `py --version` 能输出版本；Linux/macOS 使用 `python3 --version`。以下所有 Python 命令均在 `python-cli/` 执行。

确认设备固件模式：

| 设备模式 | USB ID | 命令的 `--interface` |
|---|---|---|
| VCAN | `1d50:6080` | `vcan_usb` |
| GS_CAN | `1d50:606f` | `vkgs_usb` |
| PCAN 兼容 | 不走本页的两个 USB 后端 | 先用[设备管理器](03_设备管理器.md)切换模式 |

以下以 **VCAN** 为例。GS_CAN 用户将示例中的后端 `vcan_usb` 换成 `vkgs_usb`，内核测试脚本的目录和文件名也同样替换。Linux 可用 `lsusb` 查 USB ID；虚拟机用户先将设备连接到虚拟机。

## 2. 安装 Python 环境

Windows：先给每个 CAN 子接口 `MI_00`、`MI_01` 安装 WinUSB。需要手动绑定时，从 [Zadig 官网](https://zadig.akeo.ie/)获取工具，勾选 `Options → List All Devices`，根据 VID/PID 选中对应 **MI 子接口**，选择 WinUSB。不要选择 USB 复合父设备或其他设备。然后运行：

```powershell
py canctl.py setup
py canctl.py doctor
```

Ubuntu/Debian Linux：

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip libusb-1.0-0
python3 canctl.py setup
```

macOS：先安装 Python 3 和 Homebrew；按 [Homebrew libusb 说明](https://formulae.brew.sh/formula/libusb)安装原生库，然后：

```bash
brew install libusb
python3 canctl.py setup
python3 canctl.py doctor
```

`setup` 默认安装两个后端，环境放在用户本地磁盘，可避开 HGFS 共享盘的 venv 错误。不要加 sudo，也无需手动激活环境。已有环境的选择顺序及故障处理见[常见问题](02_常见问题.md)。

## 3. Linux 一次配置，以后免 sudo

先预览规则，再用管理员权限安装一次：

```bash
python3 canctl.py permissions
sudo python3 canctl.py permissions --apply
```

规则仅授权这两种设备给当前用户主组。若以 root 直接登录，安装时加 `--user 用户名` 指定普通用户。

**拔掉设备再插上**；虚拟机重新连接 USB 到客户机。随后不用 sudo 执行：

```bash
python3 canctl.py doctor
```

目标设备应显示 `read/write=yes`。若显示 `driver=vcan_usb`、`vkgs_usb` 或 `gs_usb`，说明 SocketCAN 内核驱动仍占用接口。先关闭 `candump` 等程序，复制 doctor 为**目标板卡**生成的释放命令。例如当前 USB 拓扑为 `1-1`：

```bash
sudo python3 canctl.py release --interface vcan_usb --usb-path 1-1
```

`1-1` 是示例，必须以 doctor 输出为准。release 只解绑所选板卡。

重插后内核可能再次绑定，此时重复 release。查询已绑定设备的 UUID 可直接读 sysfs，见[身份定位](09_SocketCAN使用手册.md#定位唯一板卡和通道)。

## 4. 找到板卡和通道

以下命令 Linux/macOS 原样执行，Windows 只把开头的 `python3` 换成 `py`。后续参数完全相同。

```bash
python3 canctl.py --interface vcan_usb list
python3 canctl.py --interface vcan_usb --channel 0 info
```

`list` 应显示 `channel=0`、`channel=1`；`info` 输出多行格式化的精简 JSON，包含模式、通道、版本、UID、UUID 和 `identity_key`，可直接用程序解析。`list` 仅发现设备；`info` 会打开目标接口。完整原始字段用 `info --json` 查看。

一块板卡用完整 UID/UUID 定位；具体通道用 **UUID + channel**，例如 `<uuid_hex>:0`。外壳 CAN1/CAN2 与软件编号 0/1 的对应关系按板卡说明登记。

多设备时先用 `--device` 或 `--usb-port-path` 选设备，再用 `info` 核对 UUID。USB 地址、端口和 Linux `canX` 都可能变化。`--usb-port-path` 与 release 的 `--usb-path` 格式不同，见[终端工具](04_Python终端工具.md)。

## 5. 接线并收发第一帧

在独立测试总线上把通道 0 的 CANH 接通道 1 的 CANH，CANL 接 CANL；参考地接法按硬件说明。总线两端各有一个 120 Ω 终端。以下示例打开两个内置终端；已经装有外部终端时改为 `--termination off`，避免重复。

打开两个终端窗口，都进入 `python-cli/`。先在窗口 A 运行接收：

```bash
python3 canctl.py --interface vcan_usb --channel 1 --bitrate 500000 --termination on recv --count 1 --timeout 30
```

30 秒内在窗口 B 发送：

```bash
python3 canctl.py --interface vcan_usb --channel 0 --bitrate 500000 --termination on send 0x123 11223344
```

Windows 将上述两条命令的 `python3` 改为 `py`。

预期发送端显示 `TX 1/1`，接收端显示 ID `123` 和数据 `11 22 33 44`。超时表示没有收到帧，先检查发送端和接线。按 `Ctrl+C` 结束接收。

## 6. 运行同一套完整测试

关闭上述收发窗口中的程序，保持两个通道接在同一测试总线上。完整测试会更改两路位率、终端电阻及状态并发送大量数据；不要连接正在运行的业务总线。测试默认开启两路内置终端，应移除重复的外置终端。

Linux/macOS：

```bash
python3 canctl.py test --interface vcan_usb --frames 2000 --results-json results.json
```

Windows：

```powershell
py canctl.py test --interface vcan_usb --frames 2000 --results-json results.json
```

`--frames 2000` 表示每个发送端、每阶段 2000 帧。两路须支持 CAN FD。成功标志为 `COMPLETE PYTHON USB SUITE PASSED`；失败时保留终端输出和生成的 `results.json`。检查项见[验证路线](10_验证路线.md)。

## 7. Linux 切回 SocketCAN

关闭 Python 程序后重插设备；已加载匹配驱动时通常会重新绑定。需要从源码编译和加载时，从**仓库根目录**执行（先按[安装说明](08_Linux内核驱动安装.md)安装编译依赖）：

```bash
sudo bash kernel/tests/vcan_usb/test_vcan_usb.sh --load-only
```

此命令不发送 CAN 帧。确认两路已绑定后，再在正确接线下运行：

```bash
sudo bash kernel/tests/vcan_usb/test_vcan_usb.sh --no-build --frames 2000
```

`--no-build` 不编译也不加载驱动。测试临时加载的 VCAN 模块用 `sudo rmmod vcan_usb` 卸载，GS_CAN 对应 `vkgs_usb`；先关闭使用模块的程序。详见[常见问题](02_常见问题.md)。
