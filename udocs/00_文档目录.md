# 文档目录

以下通用示例以 **VCAN（`vcan_usb`）** 为主；设备处于 GS_CAN 模式时，按对应说明改用 `vkgs_usb`。先看 [01_快速入门](01_快速入门.md)：识别设备模式、安装、定位通道、收发第一帧。遇到报错按 [02_常见问题](02_常见问题.md) 中的原始错误查。其余文档按用途阅读，不需要从头读到尾。

| 文件 | 什么时候看 |
|---|---|
| [03_设备管理器](03_设备管理器.md) | 在 Windows 查看设备、切换 VCAN/GS_CAN/PCAN 模式 |
| [04_Python终端工具](04_Python终端工具.md) | 查 `canctl.py` 的查询、收发、测试参数 |
| [05_PythonCAN使用手册](05_PythonCAN使用手册.md) | 用 `python-can` 开发程序、选设备、管理生命周期 |
| [06_API验证](06_API验证.md) | 运行最小双通道 `can.Bus` 收发示例 |
| [07_PythonAPI参考](07_PythonAPI参考.md) | 查 Python API 参数和返回值 |
| [08_Linux内核驱动安装](08_Linux内核驱动安装.md) | 安装 SocketCAN 驱动，处理绑定问题 |
| [09_SocketCAN使用手册](09_SocketCAN使用手册.md) | 使用 `canX`、`candump`、`cansend`，查询 UID/UUID |
| [10_验证路线](10_验证路线.md) | 在第一帧成功后做完整双通道验收 |
| [11_CANopen与DBC开发指南](11_CANopen与DBC开发指南.md) | 开发上层协议或解析信号 |

一块硬件用完整 UID/UUID 定位，具体通道再加板内 `channel` 号。`canX`、USB 地址和枚举序号可能变化。已绑定 SocketCAN 时按[身份查询](09_SocketCAN使用手册.md#定位唯一板卡和通道)读取 sysfs；Python USB 使用 [`info`](04_Python终端工具.md#31-只查询板卡身份)。
