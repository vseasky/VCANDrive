# Windows 设备管理器

`USB_CAN_Device_Manager.exe` 用于查看设备信息、切换工作模式和设置每路 CAN 的内置终端电阻。它是单独交付的 Windows 程序，不在公开源码仓库中。界面不包含收发测试或固件升级功能。

## 第一次打开

1. 用 USB 数据线连接设备，关闭正在使用设备的抓包或收发程序，打开 `USB_CAN_Device_Manager.exe`。
2. 等待自动识别；如果刚插上设备，点右上角“刷新设备”。列表中的每一行代表一台设备，多路通道合并为一行。多台设备同时接入时，先看 UID，再选中要操作的一行。
3. 核对“当前模式”“固件版本”“硬件版本”“USB 速率”“隔离类型”和各通道“终端电阻”。USB 速率显示 `FS` 或 `HS`，表示当前 USB 连接速度；隔离类型显示“隔离”或“非隔离”。旧版固件无法返回速率时显示“未知”。

## 设置终端电阻

选中设备后，下方“终端电阻”区域直接列出它的所有 CAN 通道。每路都有独立开关，蓝色为开，灰色为关；状态未知时开关不可操作，先刷新。点击开关后，程序会核对所选设备身份、设置这一通道、再从设备回读；完成后列表和开关一起更新。操作过程中等待结果，不要重复点击。

总线两端各需一处 120 Ω 终端。若同一位置已接外置终端，应保持该路内置终端关闭。切换模式后，程序会重新枚举并重新读取各通道状态。

## 切换工作模式

选中设备，在“目标模式”选择 VCAN、PCAN 或 GS_CAN，点击“切换模式”。设备会短暂断开并重新枚举；程序按 UID 找回设备，核对完整身份和目标模式。切换到另一模式后，Windows 可能需要对应驱动。当前模式已经是目标模式时，无需重复切换。

## 看不到设备时

先检查供电、数据线和 Windows 设备管理器中的 USB 枚举，再关闭占用该设备的其他程序并刷新。VCAN 和 GS_CAN 模式按[快速入门](快速入门.md#2-windowspython-usb-路线)检查每路 `MI_xx` 的 WinUSB 驱动；PCAN 模式需要兼容驱动以及系统可用的 `PCANBasic.dll`。PCAN 通道被其他程序占用时，设备管理器不会抢占它。

PCAN 模式下，旧固件如果不支持管理握手与读取设备信息，列表不会把它误认作本项目设备。此时先在可识别的模式下升级到支持管理接口的固件。状态栏若显示“结果不确定”，应关闭占用程序、刷新并确认实际状态，再决定是否重试；程序不会自动重发写命令。

## 开发者说明

VCAN/GS_CAN 从现有 USB 信息接口读取 40 字节设备信息；PCAN 使用 [管理帧协议](PCAN设备管理.md)读取同一信息。PCAN 自动探测以只听模式打开空闲通道，只显示通过握手、UID 和 CRC 校验的设备；多通道按 UID 合并。写操作在已核对身份的句柄上执行，终端设置后回读，模式切换后重新枚举验证。UID 与 CRC 是避免误操作的检查，不构成身份认证。

硬件版本显示完整的 32 位十六进制值。隔离类型取自硬件版本的能力位，USB 速率取当前 USB 连接；二者与工作模式是不同信息。当前单台设备的多通道与三模式已实测，多设备同时接入的选择逻辑经过模拟验证。
